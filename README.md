# 七叔行业平台 Demo

访问：https://hewei1223456-max.github.io/qishu-industry-demo/

女装行业平台交互演示。所有账户、价格、报名、支付、认证与运营数据均为本地模拟；不接入真实交易或身份核验。

- 游客 → 填写资料 → 任意示例图片作营业执照 → 图片解码后自动弹出拼图 → 认证店主。
- 厂家独立找店主与需求沟通；资讯瀑布流、一起游学、同行内容、独立组局页与货源订货会；创作者中心仅店主端使用。
- 厂家免费/基础/高级/企业版，可切换演示权限；岗位子账号按权限操作；订货会可保存草稿、编辑和发布。
- 行业资讯有可核对来源；经营工具包含同行爆款、同城爆款和低粉爆款参考，视频使用抖音官方播放器。
- 讲师课程平台30%、讲师70%；其他模拟收入平台100%。

纯静态 HTML/CSS/JavaScript，入口 index.html，hash 路由，可部署到任意静态托管。数据保存在当前浏览器，上传图片只在当前页面预览，不传输到服务器。

下载 offline-demo.html 后可离线打开应用与本地演示。抖音视频播放、外部来源仍需联网。
