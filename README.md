# 七叔女装行业平台

本工程依据2026年11月10日MRD重构，用于微信小程序优先开发及前后端交互演示。原静态Demo保留，不在其全局脚本上继续叠加补丁。

## 运行

需要Node.js 24，无需安装第三方Node运行包。Windows双击“启动演示.cmd”（会查找本机Node或Codex运行时），或在工程目录运行：

```sh
npm start
```

服务启动后访问 http://127.0.0.1:4188 。本地数据、上传和密钥存储位于被Git忽略的data目录。请勿把data目录提交仓库或将开发演示当作真实微信认证。

- 前台演示入口：http://127.0.0.1:4188/#/login?entry=front
- 后台演示入口：http://127.0.0.1:4188/#/login?entry=back

前台切店主或厂家，后台切厂家经营后台或平台运营后台；顶部也可随时切换演示视角。正式模式隐藏这些体验入口。店主和厂家个性化推荐默认开启，保留用户主动关闭的选择。

进入“登录演示”选择未认证店主、认证店主、厂家或平台运营。未认证账号隐藏拿货价、起批及联系方式；认证审核、线下权益开通、内容发布均由后台执行。所有初始商家和资料明确标为示例。

大文件解析另需Python及 `python -m pip install -r packages/ingestion/requirements.txt`；本机启动脚本会优先使用已有Codex运行时。PPTX与ZIP结构处理使用标准库，PDF与图片预览使用所列依赖。完整容量测试脚本另需 `python-pptx==1.0.2`，不会在正常启动时生成测试大文件。

## 目录

| 目录 | 用途 |
| --- | --- |
| apps/miniprogram | 原生微信小程序源码及导入说明 |
| apps/web | 浏览器演示、厂家后台及平台运营后台 |
| apps/server | 持久化业务接口、账号权限、配置、任务与推荐 |
| packages/contracts | 跨端API约定 |
| packages/platform-adapters | 平台能力边界；未实现平台明确标注 |
| packages/ingestion | 8MiB分片、最高1GiB、资料拆解与审核发布 |
| tests | 权限、数据及关键路径验证 |
| docs | 完整MRD、架构及本轮验收记录 |
| deploy | 静态网页/API分离的待部署模板 |

店主入口为资讯、找货源、店铺诊断、我的；厂家入口为资讯、货源广场、找客户、我的。平台管理员使用独立管理菜单。权益首发采用线下确认后后台开通，不提供商品交易。

## 能力状态

最终实际完成状态以交付时的验证记录为准。API密钥、AppID和正式主体资质未提供时，相应接口必须明确显示未配置，不得用演示登录或固定模板冒充真实授权、AI调用或模型效果。测试样本、模拟行为与真实经营数据分开标识。

微信正式登录、手机号授权、云端部署、备案、类目及平台审核需要各自完成条件。抖音、独立App和厂商渠道属于后续扩展边界，不因存在适配文件就视为已兼容或上架。

模型路由已实现能力匹配、渠道优先级、同能力失败切换、平台/任务/供应商分层提示词和任务持久化。供应商的真实模型ID、密钥与费用没有预填。视频自定义接口目前只接一次返回最终媒体链接的协议，返回异步jobID的供应商需要单独轮询适配，不把jobID当生成视频。

双塔包含真实独立矩阵训练与召回，使用合成偏好和本站测试事件验证流程；生产推荐效果尚无真实用户评测。私有知识只在本人/主体授权范围使用，授权摘要可参与推荐，原件不会默认汇入公共训练。

批量导入入口在“平台运营 → 内容与素材 → 批量导入”，支持多文件队列、分片续传、结构拆卡、人工编辑和确认发布。AI文本归类异步分批，图像/扫描件和音视频会明确记录尚待理解的范围；上传1GiB不等于已完整理解1GiB真实资料。单任务结构处理最多300页/文档、500卡片，超限会提示分批。

管理员按 `resource:read/write/*` 授权，例如 `content:read,content:write`；`*`是最高权限。原件导入还需 `ingestion:read/write`，公开发布需目标内容权限。正式管理员必须本人微信及手机号绑定；不能手填微信昵称获得权限。

微信工程导入与待验证项见 [小程序说明](apps/miniprogram/README.md)，正式环境与首次管理员见 [服务端说明](apps/server/README.md)。GitHub保存的是源码，不能直接运行Node后端；新版公网部署仍需腾讯云资源、域名和HTTPS，不使用临时本地进程冒充长期服务。

接口和权限在服务端控制，密钥不得进入前端或Git。修改后的功能需验证故障降级、返回状态、字体放大和角色隔离。
