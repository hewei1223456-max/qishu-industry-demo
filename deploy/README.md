# 部署接入说明

此目录是待云资源联调的部署模板。本机没有Docker，尚未执行镜像构建、腾讯云部署或公网验收。

1. 按服务端环境说明填写仓库根 `.env`，仅服务器保存，禁止提交。正式环境关闭开发登录。
2. 执行 `docker compose -f deploy/compose.yaml up -d --build`。网页与API分别运行，SQLite、原件与密钥保存在持久卷；模板只绑定本机8080，不能直接当公网HTTPS入口。
3. 在腾讯云负载均衡或已有反向代理上配置域名、有效HTTPS证书、安全策略、日志与备份；小程序配置对应合法域名。实际产品、地域及网络按采购结果确定。
4. 手机开发者工具及真机分别验证微信授权、手机号、上传、播放、返回、大字号与隐私授权，再提审。仅有域名或代码不代表通过备案、微信审核。

分片为8MiB，因此代理无需缓冲整份1GiB文件。普通素材上传接口上限25MiB，代理体积上限26MiB。并发、超时和存储额度须按真实服务器容量压测后调整。生产大规模文件建议将分片直传与私有对象存储接入；当前实现是本地磁盘存储，不冒充腾讯COS。

网页静态资源由独立Nginx提供，API故障时导航和错误页仍可显示；涉及身份、写入或动态数据的操作会明确失败。共享数据库、磁盘或主机故障依然可能影响多个业务，需要备份、监控和恢复，不能宣称任何故障都不影响操作。

首个正式管理员按服务端微信登录及手机号白名单绑定流程开通，不能在生产开启公开的“平台运营体验”接口。云端部署与备案尚未完成，不提供伪公网链接。
