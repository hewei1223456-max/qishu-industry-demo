# 七叔平台 Web

由同端 Node 服务提供静态文件及 `/api`，不需要前端构建或 npm 运行依赖。

- 前台：`/?workspace=front#/login`，只选择店主、厂家、平台管理员。
- 后台：`/?workspace=back#/login`，只选择厂家后台、平台管理员后台。
- 后台登录后在同一 `workspace=back` URL 内使用 `#/manufacturer` 或 `#/admin`。前台不会自动进入后台。

## 模块边界

- `app.js`：响应式导航壳、路由、角色守卫及页面异常边界。页面按需加载，一个页面模块加载失败时保留导航。
- `core/`：超时 API、前后台 scope、服务端会话状态、历史与筛选位置、管理菜单。
- `components/`：统一图标、表单、弹层、联系信息、推广展示。
- `pages/`：资讯、货源与订货会、客户与回访、个人创作与诊断、平台配置、批量导入等独立页面。
- `assets/`：本地演示图片；资讯与货源均为双列自然高度卡片。不会把纵向图片拉伸。

## 数据与权限

业务读取和写入统一调用后端，前端不保存模型密钥。开发登录不代表微信登录或真实资质。未认证账号使用后端裁剪后的公开信息，权限及主动联系额度以服务端校验为准。

所有 API 使用固定 `X-Qishu-Scope: front|back`。登录 body 同步 scope，服务端为前后台使用独立 Cookie/Bearer 会话。一端切身份或退出不改变另一端。各端只能回到本端登录页切换身份；没有跨端六场景切换。正式管理员注册仅说明授权申请，不会自助提权。

素材先私有上传：创作素材使用 `purpose=content`，证照和诊断原件使用私有用途。后端审核发布后才公开可发布的素材。证照与私有知识不随普通内容公开。

AI未配置、模型失败、解析失败和队列状态分开显示。图像、音频和视频只展示真实任务结果。联系点击只记录意向，不当作已经加微信或成交。

## 交互

店主和厂家拥有不同的四个主入口。“我的”包含经营资料、创作中心、偏好、私库及任务。平台后台与厂家后台使用独立管理导航。弹层进入浏览器历史；返回先关闭弹层，页面返回保留筛选和滚动位置。手机安全区和大字号参与布局，不接管系统手势。

厂家认证提交营业执照、至少30秒经营场所视频和5张不同场所照片。浏览器 metadata 仅即时预检，实际时长、文件归属及材料条件由服务端核验。管理员在后台查看私有材料、记录实际电话回访后人工审核；缺材料、视频不合格或电话回访未通过时不能批准。私有图片、视频和音频 URL 带本端 scope，不能改成公开素材。

批量资料导入位于“内容与素材 → 批量导入”，文件队列2个并行、同文件4片并行、8MiB切片。重选同一原文件可尝试续传。拆解后的卡片需人工检查、编辑及确认发布。

正式微信登录、手机验证、真实模型渠道、公网数据库和部署应按根目录部署说明完成联调。当前开发页面可展示相应配置状态，不能代替微信真机或平台审核验收。
