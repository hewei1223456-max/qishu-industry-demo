# 七叔平台 · 微信小程序原生工程

这是可导入微信开发者工具的原生 JS/WXML/WXSS 源码，独立于网页工程。当前是开发演示与接口联调版本，尚未取得微信编译、真机和上架结果。

## 导入与启动

1. 在仓库根目录启动 API：`npm run start`（以仓库根 README 的实际启动命令为准），默认服务 `http://127.0.0.1:4188`。
2. 微信开发者工具「导入项目」选择本目录 `apps/miniprogram`。目前 `project.config.json` 使用 `touristappid`，适合先检查工程；真实微信登录、预览上传与发布需要替换为自己的有效 AppID。
3. 打开「我的 → 登录与体验」，开发演示入口分别提供店主和厂家测试账号。服务端必须启用演示模式；正式发布前关闭客户端 `config.js` 的 `demoEnabled` 以及服务端演示入口。
4. 本地 HTTP 调试可能需要开发者工具的本地开发设置；**生产包必须使用 HTTPS 和微信后台合法域名**，不能依赖开发时的域名校验开关。
5. 真机不能用手机的 `127.0.0.1` 访问电脑。真实联调使用部署好的HTTPS API域名。临时局域网调试需要服务器显式监听局域网，并在登录页填写电脑局域网地址；必须使用独立合成测试库，本机含私有原件的演示库不向公网开放。这里保存的是API源站，不含 `/api`。

当前未在本机发现微信开发者工具，不能将 Node 检查结果称为微信编译成功。导入后如需检查基础库兼容性，应以所用开发者工具的实际编译结果为准。

## 已提供的页面与交互

| 店主四个入口 | 厂家四个入口 | 内容 |
|---|---|---|
| 资讯 | 资讯 | 双列瀑布流、图片原比例、搜索分类、资讯详情、发布资讯 |
| 找货源 | 货源广场 | 六项筛选、订货会三秒轮播、货源详情、联系意向与联系方式 |
| 店铺诊断 | 找客户 | 资料诊断 / 私有知识咨询；厂家客户需求列表、详情、主动联系与额度 |
| 我的 | 我的 | 双端创作中心、草稿与审核、联系方式回访、认证、4–10 标签、推荐开关、私有知识库 |

订货会属于货源内活动。创作支持文字、图片、视频和音频文件；诊断支持图片、视频、录音与文件辅助输入。OCR/ASR/生成任务走统一服务器任务接口；未配置渠道或凭证时显示实际错误，不输出假结果。PPTX、PDF、ZIP 等大批量资料及最高 1GB 的异步导入以电脑运营后台为主入口，不使用微信原生上传承诺 1GB 文件。

本平台不生成货品订单、不收货款。权益在线下购买后由平台开通；套餐名称、额度、联系方式及到期规则以后台配置为准，不在客户端硬编码免费十次为商业承诺。

## 微信登录与认证状态

- 「微信登录」调用真实 `wx.login` 并交给 `/api/auth/wechat`；没有服务器 AppID / AppSecret 时返回未配置，开发账号不冒充微信身份。
- 手机号授权使用原生 `getPhoneNumber` 入口；是否可用由主体能力与服务器配置决定。
- 执照上传为私有文件。上传后提交 AI 辅助识别与人工终审申请，不在客户端自动批准。
- 「服装批发 / 零售」满足行业范围条件，仍需核对主体信息一致性；界面使用「资质已审核」，不承诺内容绝对真实。
- 联系操作由服务端记录意向与额度；复制联系方式不代表微信好友添加成功，也不自动标成成交。

## 导航、适配与隔离

页面使用原生导航栈和系统返回，详情返回不重新构建列表，保留筛选和列表实例。没有历史页面时返回相应 Tab。iOS / Android / 鸿蒙微信的系统手势由微信客户端处理，不强制拦截或反转手势。

适配层读取系统字号，使用相对字号与安全区内边距；大字号下将密集卡片与筛选逐列展开。图片 `widthFix` 保持原比例。轮播和轮询在页面隐藏时停止，诊断失败仅显示本模块错误，其他入口仍可使用。

Web、抖音和原生 App 的状态见 `../../packages/platform-adapters/README.md`；抖音 / App 当前只有契约预留，不是已经验证的端。

## 检查

在本目录运行：

```sh
npm run check
# API 4188 正在运行，且允许演示账号时：
npm run smoke
```

`check` 验证 JS 语法、JSON、路由、动态控制绑定、事件函数和包内 require；`smoke` 用 wx 桩驱动页面逻辑，访问真实本地 API。它们都不替代微信开发者工具编译、WXML 运行渲染和真实设备验证。隐私授权弹窗、相机、麦克风、分享、媒体播放、手机网络与上架材料仍需在正式主体和真机环境验收。

AppSecret、API Key、系统提示词和平台官方知识底库均不进入小程序源码或 bootstrap。用户私有知识库按服务端身份隔离。

原生端未把预加载列表当作曝光，仅报告真实搜索、点击与详情前台停留。实际可见曝光观察尚未做真机验收。默认货源读取个性化推荐，任何主动筛选走严格货源查询。公开联络设置默认不同意，保存后仍由服务端控制身份、权益与渠道；微信号/电话可复制，二维码通过原生图片预览打开。
